**Cyber Survivors: Neon Protocol** is an addictive, fast-paced 2D roguelite action web game built inspired by the global mega-hit *Vampire Survivors*. Developed from the ground up with high player session retention, viral mechanics, and turnkey monetization in mind, this asset is fully ready for immediate commercial deployment.

   - In-game currency ("Cyber Credits") collected during runs to permanently upgrade base player attributes in the Armory.

3. **Cross-Platform & Mobile Ready**:
   - 100% responsive HTML5 Canvas 2D engine running at a smooth 60 FPS.

4. **Procedural Zero-Asset Sound Engine**:
   - Custom Web Audio API synthesizer generating real-time synthwave music, laser blasts, explosions, level-up fanfares, and coin sounds with zero external audio assets to host.
5. **Global REST API Leaderboard**:
   - Lightweight Node.js/Express backend that persists top scores, kill counts, and survival times.
